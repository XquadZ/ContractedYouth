### 리포트 맨 위 문구 기준 3단계 (제안값 · 검토 필요)

| 조건 | 문구 | 근거·메모 |
|---|---|---|
| 위반·위험 0, 확인 필요 0~2 | 큰 문제는 보이지 않아요 | 확인 필요 2건까지는 ‘사소한 모호함’으로 보자는 **제안**. 법령 수치 아님. **검토 필요** |
| 위반·위험 0, 확인 필요 3 이상 | 직접 확인할 부분이 있어요 | 확인 필요가 쌓이면 사용자 확인 부담이 커진다는 UX 제안. **검토 필요** |
| 위반·위험 1 이상 | 고쳐야 할 조항이 있어요 | 위반 1건만 있어도 상단 경고. **검토 필요** |

숫자 2·3은 서비스 UX 제안이며 법령 근거 없음.

## 4. 근로시간·휴게

### 표준계약서 문구 `[표준]`
파일 원본: `datasets\work\표준_근로계약서(7종)(19.6월).hwp` → `_std_forms/`

- **기간없음/있음:** `4. 소정근로시간 : 시 분부터 시 분까지 (휴게시간 : 시 분~ 시 분)`
- **단시간:** `4. 근로일 및 근로일별 근로시간` + 표 칸(원문에서 표 셀로 분리됨)
- **차이:** 단시간은 일별 근로시간 표기. 전일제는 시업·종업·휴게 시각.

### 법 요건
- `[법]` 제54조: 4시간→30분 이상, 8시간→1시간 이상, **근로시간 도중에** · `근로기준법_body_MST.json`
- `[법]` 제50조: 1주 40시간·1일 8시간(휴게 제외) · `근로기준법_body_MST.json`
- `[법]` 제50조 ③ 대기시간은 근로시간으로 볼 수 있음.

### 안전 기준 (문제 없음)
- 휴게가 제54조 기준 이상이며 근무 도중에 부여
- 소정근로가 1일 8시간·1주 40시간 이내로 명시(특례·합의 없으면)

### 위반 기준
- 휴게 미부여·미달 (제54조 — 4명 이하에도 적용)
- 휴게를 퇴근 후에만 부여
- 1일 8시간·1주 40시간 초과를 상시로 정함(**상시 5명 이상**, 제50조) `[지식·원문 대조 필요]`

### 확인 필요 조건
- ‘한가할 때 휴게’ → 실제 자유이용 가능 여부
- 대기시간 포함 여부
- 40시간 초과 소정인지와 상시 5명 여부(제50조 적용 시)

### 적용 범위
- `[법]` 제11조: 원칙 상시 5명 이상. 4명 이하 일부적용은 시행령 제7조·**별표1**.
- 별표1 본문은 MST에 제목·파일링크만 있고 **본문 텍스트 없음** → 구체 조항 목록은 `[미확인]`.
- 단시간·초단시간도 휴게 산정은 실제 근로시간 기준.

### 안전 표현 예시 (새로 작성 · 정답문장 아님)
1. 근무 09:00~18:00, 휴게 12:00~13:00(1시간)로 한다.
2. 4시간 근무 시 30분 휴게를 근무 도중에 부여한다.
3. 1주 소정근로시간은 휴게를 제외하고 40시간 이내로 한다.

### 독소 표현 예시 (새로 작성 · 정답문장 아님)
1. 휴게는 없으며 퇴근 후 알아서 쉰다.
2. 휴게 10분만 부여한다(8시간 근무).
3. 소정근로를 1일 10시간으로 고정한다(별도 합의·특례 없음).

### 흔한 오판
- 시급만 있고 휴게 칸이 비어 있으면 누락(확인/위반) — ‘최저임금 OK’와 혼동 금지.
