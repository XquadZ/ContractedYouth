            HOW IT WORKS

            이용 방법

            1. 유형을 고릅니다. 부동산·근로·금전거래 중 지금 계약에 맞는 칸을 고르세요.
            2. 문장을 넣습니다. .txt 파일을 올리거나 본문을 붙여 넣습니다. 예시 계약서로 먼저 과정을 볼 수 있습니다. 원문은 디스크에 저장하지 않습니다.
            3. 과정을 봅니다. 나누기 → 사실표 → 검색 → A.X 판정 → 검증 → 리포트 순서로 진행됩니다.
            4. 조항별로 확인합니다. 위반·위험·확인 필요·문제 없음과 근거 ID, 인용문을 함께 봅니다.

            자주 묻는 질문

            계약서가 서버에 남나요?
            남기지 않습니다. 점검을 위해 메모리에서만 읽고, 로그에는 조항 수·지연·판정·근거 ID만 남깁니다.
            외부 AI를 쓰나요?
            쓰지 않습니다. 검색은 로컬 BM25와 bge-m3, 판정은 이 컴퓨터의 A.X 4.0 Light(8082)만 사용합니다.
            결과를 변호사가 써 준 건가요?
            아닙니다. 이해를 돕는 정보이며 법률 자문이 아닙니다. 고용노동부 1350, 대한법률구조공단 132에 확인하세요.
            A.X가 꺼져 있으면요?
