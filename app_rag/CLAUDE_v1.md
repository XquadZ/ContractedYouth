# app_rag — 청년 계약서 독소조항 점검 (AI서비스개발 1조)

## 무엇을 만드나
근로·주택임대차·금전차용 계약서를 넣으면 위험 조항을 표시하고, 근거 조문과 수정 문구를 보여 주는 로컬 RAG 서비스.
- 학습 모델은 쓰지 않는다. 검색(BM25 문자 bigram + bge-m3, RRF) → 로컬 A.X 4.0 Light 판정 → 코드 검증 → 리포트.
- 서버: FastAPI `8091` (`server.py`), A.X llama-server `8082` (`start_ax.py`, `data_local\models\A.X-4.0-Light-Q8_0.gguf`, ctx 8192)

## 작업 방식
- 할 일과 완료 기준은 `docs\MVP_PLAN.md`에 있다. 그 순서대로 진행하고, 단계마다 `docs\PROGRESS.md`에 기록한다.
- 단계별 세부 지시는 `docs\tasks\*.md`에 있다. 문서 이름은 `CURSOR_PROMPT_*`이지만 그대로 따른다.

## 절대 규칙
1. **파일 삭제 금지.** 바꿀 파일은 아직 없는 이름 `*_v숫자.py`로 백업한 뒤 고친다.
2. **설정 고정:** A.X(temperature, max_tokens, ctx), 검색(상위 3, 하한 0.016, RRF k=60)은 바꾸지 않는다.
   - 실행 시간이 길다는 이유로도 바꾸지 않는다.
   - 꼭 바꿔야 하면 멈추고 사용자에게 이유를 묻는다.
3. **외부 API:** OpenAI API는 ① dev/test 평가와 ② 시연 모드에서만 쓴다.
   - 보내기 전에 반드시 개인정보 마스킹(`rag/pii.py`)을 거친다.
   - 키는 환경변수 `OPENAI_API_KEY`에서 읽고, 어디에도 출력하지 않는다.
   - 다른 외부 API(클라우드 OCR, 리랭커 등)는 쓰지 않는다. 법령 API(`LAW_OC`)는 사용자가 설정했을 때만 쓴다.
4. **키 값**(OC, HF_TOKEN, OPENAI_API_KEY 등)은 어디에도 출력·기록하지 않는다.
5. **사용자 계약서 원문:**
   - 업로드 원본 파일은 AES-256-GCM으로 암호화해서 DB에 저장하고, 만료되면 자동 삭제한다.
   - 추출 텍스트는 **마스킹 후에만** 저장한다.
   - 로그에 원문·개인정보를 남기지 않는다. 로그에는 조각 수·시간·판정 수·근거 ID만 남긴다.
6. **평가는 dev만 쓴다.** `datasets\splits\dev_test_split.json`을 따른다. test는 `MVP_PLAN.md`의 마지막 단계에서 **한 번만** 돌린다.
7. **정답 데이터 문장**(datasets 01 파일의 text)을 프롬프트·기준 카드·예시에 넣지 않는다. 평가가 부풀려진다.
8. **증거 규칙:** "완료/통과/✓"만 쓰지 않는다.
   - 모든 숫자에 명령과 출력 파일 경로를 붙인다.
   - 확인 못 한 것은 "미확인"으로 쓴다.
   - 결과가 나쁘면 돌려 말하지 말고 그대로 적는다.
9. **git 저장소에는 원문을 올리지 않는다.** AI Hub 원문, 사용자 계약서가 대상이다.
