# RULE_PII_FIX2 — 표 안의 이자율, 근거 없는 '위반', 판정·설명 불일치

RULE_PII_FIX의 후속이다. 지켜야 할 것(백업 `*_v숫자`, 삭제 금지, llama-server 재시작 금지, 검색·모델 설정 변경 금지, 키 출력 금지, criteria/corpus 수정 금지, 출력 원문 첨부)은 그대로 적용한다.

## 0. 사용자가 올린 계약서 (2쪽 PDF, 금전차용증서)

**1쪽 (2026-03-06 작성)**
- 표: 차용금액 `일금 일천만 원정 (₩ 10,000,000)`. 이자, 상환방법, 차용기간, 상환일자 칸은 비어 있음. 채권자 칸도 비어 있음.
- 본문
  - `1. 24년도 3월 일금 이천만원(₩20,000,000) 차용하여 매월 일십만원씩 이자를 상환한다`
  - `2. 24년도 3월에 차용한 이천만원과 이번 26년도 일천만원 차용하여 총 삼천만원 차용함`

**2쪽 (2024-03-29 작성)**
- 상단 메모: `(문서 상단 손글씨 메모: 3000천만원)`
- 표: 차용금액 `일금 이천만 원정 (₩ 20,000,000)`, 이 자 `10%`, 상환방법 `매월 27일 (개시일 2024.04.27)`, 차용기간 `12개월`, 상환일자 `2025년 03월 27일`

**서비스 결과:** 판정 카드 1개뿐이다.
- 1쪽 1번 조항에 **'우선 확인 · 위반'**
- 설명: "이자율이 명시되지 않아 법정 최고이자율 준수 여부를 확인할 수 없습니다."
- 근거: "근거를 찾지 못해 직접 확인이 필요해요"

**올바른 결과**
- 이자율은 위반이 아니다.
  - 2쪽: 연 10%
  - 1쪽: 2천만 원에 월 10만 원이면 연 6%
- 대신 확인이 필요한 점들이 있다.
  - 같은 2천만 원의 이자가 1쪽(월 10만 원, 연 6%)과 2쪽(연 10%, 월 약 16.7만 원)에서 서로 다르다.
  - 1쪽 추가 차용 1천만 원은 이자, 변제기, 채권자 인적사항이 비어 있다.
  - 메모 `3000천만원`은 금액 표기가 모호하다.

## 1. 원인 확인 (먼저, 수정 전에)

### 1-1. 표 안 이자율을 못 읽음 — Claude 재현 완료

| 입력 | 현재 결과 |
|---|---|
| `이 자 10% 상환방법 매월 27일` | `interest_rate=None` |
| `이 자\n10%\n상환방법\n매월 27일` | `interest_rate=None` |
| `이자 10%` | 0.1 (정상) |

서식 표의 항목명은 `이 자`, `성 명`, `주 소`처럼 글자 사이를 띄워 쓴다. 지금 정규식은 붙여 쓴 `이자`만 읽는다.

### 1-2. 근거가 없는데 '위반'이 나온 이유 — 미확인

서비스 설정 `ne_risky_only=True`에서는 근거가 없고 모델이 위반이면 '확인 필요'로 바뀌어야 한다. 그런데 이 결과는 '위반'이다. 아래를 확인해 원인을 보고하라.

1. 이 분석 기록을 DB에서 찾는다. 사용자 계정의 최근 금전차용 검토 기록이다.
2. 해당 조항에 대해 다음을 출력한다.
   - 모델 원래 판정
   - 최종 판정
   - `review_sources`
   - `notes`
   - 숫자 규칙 `fired` 목록
   - `facts`: principal, interest_rate, interest_rate_basis, apply_year
   - evidence 개수
3. 어느 단계가 '위반'으로 만들었는지 한 줄로 결론 낸다.
4. 문서 전체 facts가 1쪽과 2쪽 값 중 무엇으로 잡혔는지도 보인다.
5. 같은 PDF를 `rag/extract.py`로 뽑은 텍스트 원문 중 2쪽 표 부분을 보인다. 표 칸이 어떤 순서와 줄바꿈으로 나오는지 확인하는 것이다.

이 PDF 원본은 사용자 계정의 업로드 기록(암호화 저장)에서 앱 코드로 복호화해 쓴다. 디스크에 평문으로 저장하지 말고 메모리에서만 쓴다.

## 2. 수정

### 2-1. 띄어 쓴 표 항목명

- **facts 추출 전용 정규화를 추가한다.** 한글 1글자씩 공백 하나로 띄운 항목명을 붙인다. 화면 표시용 텍스트와 마스킹에는 쓰지 않는다.
  - 대상 목록: 이 자, 이 율, 성 명, 주 소, 차용금액, 차 용 금 액, 상환방법, 상환일자, 차용기간, 변 제 기, 원 금, 월 급, 시 급, 보 증 금, 차 임, 임 금
  - 목록에 있는 것만 붙인다. 아무 글자나 붙이지 않는다.
- 항목명과 값이 다음 줄이나 다음 칸에 있어도 읽는다. 예: `이자\n10%`, `이자 | 10%`
  - 항목명 바로 뒤 1~2줄 안의 첫 `숫자%`만 인정한다.

### 2-2. 이자율이 여러 개일 때

- 한 문서에서 이자율이 2개 이상 나오면 모두 `interest_rates` 목록에 남긴다. 각각 값, 근거 문장, 쪽 번호를 같이 둔다.
- 최고이자율 판정은 가장 큰 값으로 한다.
- 값이 서로 다르면 '확인 필요'를 하나 추가한다.
  - 문구: "같은 계약서 안에 이자율이 서로 다르게 적혀 있습니다(연 6%, 연 10%). 어느 것이 실제 약정인지 확인하세요."
- 원금이 여러 개일 때도 같은 방식이다. 금액 계산형 이자(월 10만 원)는 그 문장 안에 적힌 원금을 우선 쓴다.

### 2-3. 판정과 설명 일치

- 숫자 규칙이 모델 판정을 바꾸면 설명(why)도 규칙의 설명으로 바꾼다. RULE_PII_FIX 보고서의 미해결 1번과 같은 문제다.
  - 예: 위반으로 올렸으면 "연 25%로 최고이자율 연 20%를 넘습니다", 문제 없음으로 내렸으면 "연 6%로 최고이자율 이내입니다"
- **'위반'이면서 근거가 0개인 카드는 화면에 내보내지 않는다.** 이 경우는 '확인 필요'로 내리고 사유에 `no_evidence`를 남긴다. 숫자 규칙이 위반을 계산한 경우는 예외다. 그때는 근거로 해당 법 조문을 붙인다.
