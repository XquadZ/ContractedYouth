## 0. 원칙

- 외부 API 금지, 파일 삭제 금지. "완료/통과/✓"만 쓰지 않고 명령·출력을 붙인다.

## 2. 가이드 문서 `criteria\LAB_GUIDE.md` (사람이 읽고 검토하는 원본, 길어도 된다)
### 맨 앞: 계약서 전체 기준
- **"안전한 근로계약서"의 정의:**
  - 근로기준법 제17조의 필수 명시사항이 모두 있다(항목 목록을 조문에서 뽑아 적는다)
  - 아래 항목 중 위반이 하나도 없다
- **리포트 맨 위 문구 기준 3단계:**
  - 위반·위험 0, 확인 필요 0~2 → "큰 문제는 보이지 않아요"
  - 위반·위험 0, 확인 필요 3 이상 → "직접 확인할 부분이 있어요"
  - 위반·위험 1 이상 → "고쳐야 할 조항이 있어요"
  - 숫자(2, 3)는 제안값이다. 근거를 적고 "검토 필요"로 표시한다.

### 항목별 (아래 순서, 항목마다 같은 틀)

항목마다 적을 것:
- **표준계약서 문구:** 3종에서 이 항목을 어떻게 쓰는지 원문 인용. 3종이 서로 다르면 차이도 적는다.
- **법 요건:** 관련 조문 원문 인용(조·항 표시)
- **안전 기준:** 이 조건을 만족하면 "문제 없음"으로 본다. 구체적으로, 가능하면 숫자로 쓴다.
- **위반 기준:** 이러면 "위반"이다
- **확인 필요 조건:** 이때만 "확인 필요"다. 판단에 필요한 사실을 같이 적는다. 예: 상시근로자 5인 이상 여부, 1주 소정근로시간 15시간 이상 여부.
- **적용 범위:** 5인 미만 사업장 적용 여부, 단시간·초단시간(주 15시간 미만) 근로자 차이
- **안전 표현 예시 3개 / 독소 표현 예시 3개:** 새로 쓴다. 정답 데이터 문장 금지.
- **흔한 오판:** 안전한데 경고하기 쉬운 경우 1~2개
  - 예: "시급 11,000원"은 최저임금 언급이 없어도 금액이 기준 이상이면 문제 없음
  - 예: 수습 감액은 1년 이상 계약, 3개월 이내, 단순노무 아님, 10% 이내를 모두 지키면 적법

## 3. 기준 카드 `criteria\LAB_cards.yaml` (판정에 넣을 짧은 버전)
- 가이드 항목 하나에 카드 하나
- 형식:
```yaml
- id: LAB-REST          # 항목 영문 약어
  title: 근로시간·휴게
  match_keywords: [휴게, 근로시간, 근무시간, 소정근로]   # 조항이 이 카드에 해당하는지 고를 때 쓸 단어
  safe: ["4시간 근무에 30분 이상, 8시간에 1시간 이상 휴게를 근무 도중에 준다"]
  violation: ["휴게가 없거나 기준보다 짧다", "휴게를 근무가 끝난 뒤에 준다"]
  check_if: ["휴게 시각이 정해지지 않았다(예: 한가할 때 쉰다) → 실제로 쉴 수 있는지"]
  needs_facts: [일_근로시간]
  basis: [law:근로기준법:54]   # corpus ID
```
- 카드 하나는 **500자 이내**로 한다. 판정할 때 조항 하나에 카드 1~2장만 들어가기 때문이다. 글자 수를 표로 낸다.
- `basis`의 ID는 `app_rag\corpus`에 실제로 있는 ID만 쓴다. 없는 조문은 `missing_basis`에 따로 적는다.
- `match_keywords`가 카드끼리 겹치는 단어를 표로 낸다(예: "근로시간"이 휴게·연장 두 카드에 다 있음).
