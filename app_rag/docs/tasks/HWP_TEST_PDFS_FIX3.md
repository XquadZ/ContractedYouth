# HWP 시험 계약서 3차 수정 — 임대만 (HWP_TEST_PDFS_FIX3)

`HWP_TEST_PDFS_FIX.md`, `FIX2.md`의 규칙은 그대로 따른다.
- 결과는 새 폴더 `..\datasets\test_hwp_pdfs_v4\`에 만든다.
  - 근로 5장은 v3 파일을 그대로 복사한다.
  - 차용 5장은 v3를 바탕으로 4번만 고친다.
- v1~v3는 지우지 않는다. `rag\` 코드는 건드리지 않는다. 모델·GPU·판정·평가는 하지 않는다.

## 왜 다시 하나
v3 임대는 글자 검사(한 번 등장, 금지 문자열, 다름 0)는 모두 통과했다. 그런데 **사람이 쪽 그림을 열어 보니 문서가 망가져 있었다.** 예: `LEASE_toxic_LEASE-0025.pdf`
1. **1쪽 위쪽이 겹쳐서 읽을 수 없다.** 큰 글씨의 "제1조(보증금과… 3,622,000…"가 양식 머리말과 안내문 위에 겹쳐 찍혔다. 부동산 표시 표와 금액 표가 보이지 않는다.
2. 제5조~제13조와 특약은 **글자 크기가 양식 본문과 다르다**(더 크다).
3. **2쪽 서명 표에 원본 파일의 값이 그대로 남아 있다.**
   - 주민등록번호 형식 값(`990101-1000010`), 전화 `010-2910-1110`, 주소 "관악구 봉천로", 임차인 "박수연"
   - manifest의 가짜 값(임차인 박수아 등)과 다르다. 주민번호는 넣지 않기로 했다.
4. **별지 "계약갱신 거절통지서"가 이름·날짜·사유로 채워져 있다.** 빈 서식이어야 한다.

## 방법: GUI 선택·붙여넣기 대신 HWPX XML을 직접 고친다
- v3에서 `SelectText`가 불안정했고 글자 모양도 깨졌다. 그래서 이번에는 **HWPX(zip) 안의 `Contents/section*.xml`에서 `<hp:t>` 글자만 바꾼다.**
  - 문단(`<hp:p>`)과 글자 모양(charPr) 속성은 그대로 둔다.
  - 바꾼 HWPX를 한글로 열어 PDF로 저장하는 데만 한글 자동화를 쓴다.
- 조 하나의 문단이 여러 개면, 첫 문단의 `<hp:t>`에 정답 조각을 넣고 나머지 문단의 글자는 비운다. 문단 자체를 지우는 것은 표 구조가 깨지지 않을 때만 한다.
- 맨 위 표(소재지·토지·건물·임차할 부분·금액)와 서명 표의 칸도 `<hp:t>` 값만 바꾼다.
  - 이름·주소·전화는 manifest 가짜 값으로 바꾼다.
  - **주민등록번호·계좌 칸은 비운다.**
  - 중개사 칸은 "해당 없음"으로 둔다.
- 별지(중요확인사항, 계약갱신 거절통지서 등)에서 채워진 값(이름·날짜·주소·사유 체크)은 비운다. 안내 문구는 남긴다.
- 원본 파일 안의 실제처럼 보이는 값이 남았는지 확인한다. 원본 HWPX에 있던 이름·전화·주소 문자열 목록을 만들어, 결과에 0개 남아야 한다.

## 이 방법이 안 되면 (바로 대체)
XML 방법으로 1장을 만들어 4번 확인(아래)을 통과하지 못하면, 2번 더 시도한다. 그래도 안 되면 임대 5장을 **차용과 같은 방식으로 새로 만든다.** 이 경우 묻지 않고 진행한다.
- 제목 "주택임대차계약서"
- 부동산 표시와 금액 표(한글 표)
- 조항(정답 조각)
- 특약사항
- 당사자 서명 표
- 그리고 법무부 양식 맨 앞 안내문 한 문단

어느 방법을 썼는지 보고서에 적는다.

## 차용 (작은 것)
- v3에서 제목이 아직 왼쪽 정렬, 보통 굵기다. **가운데 정렬, 굵게, 본문보다 크게** 한다.
- 본문 글자 크기는 표 글자와 비슷하게 맞춘다(지금 본문이 너무 크다).

## 4. 확인 (`out\test_hwp_pdfs_v4_check.md`)
- FIX·FIX2의 글자 검사를 모두 다시 한다.
- **그림 검사를 추가한다.** 글자 검사만으로는 이번 문제를 못 잡았다.
  - 모든 쪽을 100dpi PNG로 `out\test_hwp_pdfs_v4_preview\`에 저장한다.
  - 같은 쪽에서 PDF의 글자 상자들(pdfplumber 등으로 뽑은 단어 bbox)이 서로 30% 넘게 겹치는 경우를 센다. **0이어야 한다.**
  - 본문 글자 크기 종류를 쪽마다 센다. 제목을 빼고 본문 크기가 양식과 다르게 커진 문단이 없어야 한다.
- 원본 값 잔존 검사: 원본 HWPX의 이름·전화·주소·주민번호 형식 문자열이 0개
- 빈 별지 검사: 별지 쪽에 manifest 가짜 이름이 0개
