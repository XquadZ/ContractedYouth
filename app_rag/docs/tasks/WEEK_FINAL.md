## A. GPT 평가 (모델 결정용, 가장 먼저)
**목표:** 로컬 모델과 **같은 데이터·같은 방법**으로 GPT를 평가한다. 표본 수는 로컬과 같게, 비용은 최소로.

1. **모델 고르기:**
   - API의 모델 목록(`/v1/models`)에서 지금 쓸 수 있는 범용 모델 중 두 개를 고른다.
     - **G1:** 가장 싼 소형(mini급)
     - **G2:** 대표(flagship급)
   - 정확한 모델 ID와 공식 가격(https://openai.com/api/pricing, 입력·출력 100만 토큰당)을 보고서에 적는다.
2. **같은 조건:** QUANT_FULL과 같은 것만 쓴다.
   - dev 분할: `dev_test_split_v2.json`, clean twin 포함, clean_v2 정의
   - 판정 프롬프트 `judge.txt`, 카드(가장 최근 EXAONE 실행과 같은 버전, 파일 해시를 적는다)
   - 검색 상위 3개 + 카드 basis 규칙, verify 규칙, 숫자 규칙
   - 판정 프롬프트 문구는 바꾸지 않는다.
   - 생성 설정: temperature 0, JSON 출력 강제, max_tokens 512
     - 추론형 모델이라 temperature나 max_tokens를 못 쓰면 가장 낮은 추론 강도로 하고, 출력 한도를 응답이 잘리지 않을 만큼만 늘린다. 바꾼 값과 이유를 적는다.
3. **마스킹:** 보내기 전에 B장 마스킹 함수를 거친다(B장을 먼저 만들어도 된다). 정답 데이터는 자리표시라 거의 바뀌지 않을 것이다. 바뀐 조각 수를 적는다.
4. **데이터 확인:** 평가 데이터와 corpus에 AI Hub 원문이 섞여 있지 않은지 출처 필드로 확인하고 결과를 적는다. 섞여 있으면 그 조각은 보내지 않고 멈춰서 묻는다.
5. **비용 관리:**
   - 실행 전에 토큰 수와 비용을 추정해서 적는다(조각 수 × 평균 입력·출력 토큰).
   - **A장 전체 상한은 $15.** 넘을 것 같으면 G2를 근로 dev만으로 줄이고 그 사실을 적는다. 그래도 넘으면 멈추고 묻는다.
   - 응답은 입력 해시로 캐시한다. 같은 요청에 두 번 돈을 내지 않는다.
   - API 응답의 usage로 실제 비용을 누적해서 적는다.
   - 동시 요청은 4개 이하, 실패 시 지수 백오프로 재시도한다.
6. **저장과 계산:**
   - 원래 출력은 `out\quant_gpt\<모델>_<도메인>_rows.jsonl`
   - QUANT_FULL과 똑같이 replay로 변형(AXOK, NUM2WAY, R0/R1, K)을 계산한다.
   - 같은 지표(신뢰구간 포함)와 모델별 최적 조합을 낸다.
   - McNemar로 G1/G2를 EXAONE·A.X와 비교한다.
7. **점수 공식 평가 (E장 공식 그대로):**
   - 문서마다 점수와 등급을 계산한다.
   - 깨끗한 계약서 중 "안전(80점 이상)" 비율, 독소 계약서 중 "안전이 아닌" 비율을 모델 4개(A.X, EXAONE, G1, G2) 모두에 대해 낸다.
   - missing·mismatch를 계산 못 하면 0으로 두고 "미반영"으로 적는다.
8. **보고:** `out\GPT_EVAL_REPORT.md`
   - 맨 위 표: 모델 4개 × 세 도메인. 경고 포착 / 오탐 / 과잉 경고 / 깨끗 통과 / 점수 기준 안전 비율 / 조항당 시간 / dev 전체 비용
   - 채팅에 표를 보고하고, **기다리지 말고 B장으로 넘어간다.** 시연 기본 모델은 사용자가 정한다(F장 설정값).

## C. 회원가입·로그인·사용자별 기록
- **DB:** SQLite `data_local\app.db`
  - `users`: id, login_id(unique), pw_hash, birth_date, role(user/admin), created_at, deleted_at
  - `files`: id, user_id, filename, mime, size, enc_blob, nonce, created_at, expires_at, deleted_at, deleted_by(auto/admin)
  - `reviews`: id, user_id, file_id, domain, model, masked_text, report_json, score, grade, created_at
  - `chat_messages`: id, user_id, review_id, role, content(마스킹 후), created_at
- **가입:** 아이디(영문·숫자 4~20자), 비밀번호(8자 이상), 생년월일
  - **만 19세 이상만** 가입할 수 있다(오늘 날짜 기준 만 나이 계산). 미만이면 "만 19세 이상만 가입할 수 있어요."
  - 비밀번호는 bcrypt 해시로만 저장한다.
- **로그인:** PyJWT 토큰을 httpOnly 쿠키로 둔다(12시간). 로그아웃 버튼을 만든다.
  - 비밀번호 찾기·탈퇴는 "관리자에게 문의하세요" 팝업으로 처리한다(조장 계획대로).
- **관리자 계정:** 서버 시작 시 `user1` / `pwd1`(role=admin)이 없으면 만든다. 시연용 약한 비밀번호라 8자 규칙에서 이 계정만 예외로 한다. 코드에 주석으로 표시한다.
- **로그인 필요:** 분석·업로드·기록·채팅 API는 로그인해야 쓸 수 있다. `/api/health`, 가입·로그인은 예외다.
  - 남의 review·file·chat에 접근하면 403. 테스트로 확인한다.
- **화면:** 로그인 / 가입 / "내 검토 기록"(목록 → 누르면 그때 리포트와 채팅이 다시 열림)
- **채팅 기록:** 사용자·리뷰별로 저장한다. 다시 열면 이전 대화가 보인다.

## D. 업로드 원본 저장과 자동 삭제, 관리자 삭제
- **암호화 저장:** 업로드 원본을 AES-256-GCM으로 암호화해 `files.enc_blob`에 저장한다.
  - 키는 `data_local\secret.key`(32바이트, 없으면 생성, git 제외)에 둔다. 키 값은 출력하지 않는다.
- **자동 삭제:** `expires_at` = 업로드 시각 + `FILE_TTL_MINUTES`
  - 기본 1440분(24시간). 시연 때는 환경변수로 짧게(예: 10분) 바꿀 수 있게 한다.
  - 서버 시작 시와 1분마다 만료 파일의 enc_blob을 비우고 deleted_at, deleted_by='auto'를 기록한다.
  - 검토 결과(마스킹 텍스트와 리포트)는 남는다. 원본 뷰어에는 "원본은 보안 정책에 따라 삭제됐어요"를 띄운다.
  - 화면에 "업로드 원본은 24시간 뒤 자동 삭제돼요"와 남은 시간을 표시한다.
- **관리자 화면** (user1만):
  - 사용자 목록 → 사용자를 고르면 그 사용자가 올린 파일 목록(파일명, 크기, 올린 시각, 만료 시각, 상태)
  - "원본 삭제" 버튼으로 즉시 삭제(deleted_by='admin')
  - 관리자는 계약서 내용을 보지 않는다. 파일명과 상태만 본다.
- **테스트:** TTL 2분으로 올리고 3분 뒤 자동 삭제를 확인, 관리자 삭제 확인, 삭제 후 리포트는 열리는지 확인. 스크린샷을 남긴다.

## E. 점수 공식 (조장 공식 그대로)
- 감점 = 위반×20 + 위험×12 + min(확인 필요×4, 20) + min(누락×5, 20) + min(불일치×3, 9)
- 점수 = max(0, 100 − 감점). 위반+위험이 1개 이상이면 최대 69점.
- 등급: 80점 이상 안전, 50~79 주의, 49 이하 위험
- 백엔드(report 생성)와 프론트가 같은 공식을 쓰게 하고, 단위 테스트 5개를 만든다.
- 화면에 점수 게이지와 등급을 보여 준다. "안전" 아래에는 "법 기준을 어긴 조항을 찾지 못했다는 뜻이며, 법률 자문이 아니에요."를 작게 표시한다.

## F. 분석 모델 선택
- **설정값 `ANALYZE_MODEL`:** `ax`(빠른 검토, 로컬) / `exaone`(정밀 검사, 로컬) / `gpt`(시연 모드, A장 G1 또는 G2)
  - 기본값은 A장 결과를 보고 사용자가 정한다. 그때까지는 `exaone`.
- 모델별로 A·QUANT_FULL에서 고른 최적 검증 조합을 쓴다.
- **gpt 모드:** 마스킹된 텍스트만 보낸다. 화면에 "시연 모드: 개인정보를 가린 뒤 외부 AI(OpenAI)로 분석해요"를 표시한다.
- **로컬 모드:** 한 번에 한 모델만 GPU에 올라간다. 다른 로컬 모델로 바꿀 때는 "모델 전환 중" 표시를 띄운다.
- **채팅:** gpt 모드에서는 자유 질문을 GPT로 답한다. 리포트 내용과 근거 조문만 맥락으로 넣고, 마스킹하고, 답 끝에 "법률 자문이 아니에요"를 붙인다. 로컬 모드는 지금처럼 "안내 도우미"로 둔다.

## G. 끝에서 끝까지 확인 (스크린샷)
- `datasets\demo_pdfs\`의 6개 파일로 확인한다.
  1. 만 18세 가입 거절, 만 19세 가입 성공
