# 시험용 계약서를 실제 표준 양식(HWP)으로 만들기 (HWP_TEST_PDFS)

**목적:** test 계약서 도메인별 5장, 모두 15장을 **실제 표준계약서 HWP 양식**에 넣어 HWP와 PDF로 만든다. 사용자가 실제 파일을 올리는 상황을 재현하기 위한 것이다.

`CLAUDE.md` 규칙을 따른다.
- 원본 양식 파일은 고치지 않는다. **복사본**에 작업한다.
- 파일은 지우지 않는다.
- 만든 파일은 git에 올리지 않는다.
- 이 작업은 모델을 부르지 않는다. 판정·평가는 하지 않는다(test 한 번 규칙). GPU도 쓰지 않으므로 다른 실행(FINAL_TEST)과 동시에 해도 된다.

## 0. 한글 프로그램 확인
- 이 PC에 한글(Hancom Office)이 설치되어 있고, 파이썬에서 자동화가 되는지 확인한다.
  - 방법: `win32com.client.gencache.EnsureDispatch("HWPFrame.HwpObject")` 또는 `pyhwpx`
  - 보안 모듈 경고(파일 접근 허용 창)가 뜨면 `RegisterModule("FilePathCheckDLL", ...)`로 처리한다.
- **설치되어 있지 않거나 자동화가 안 되면 멈추고 보고한다.** 다른 방법(LibreOffice 등)으로 대신 만들지 않는다.
- `pywin32`나 `pyhwpx` 설치가 필요하면 설치해도 된다(무료, 패키지 1~2개).

  - **깨끗한 계약서 2장:** toxic 0, check 0인 계약서(clean twin 포함)

## 3. 내용 채우기
- **조항 문장은 정답 파일의 text를 순서(order)대로, 글자 하나 바꾸지 않고** 넣는다. 그래야 정답 라벨을 그대로 쓸 수 있다.
  - 양식에 같은 항목(std_item)의 자리가 있으면 그 자리의 원래 문장을 지우고 정답 문장으로 바꾼다.
  - 자리가 없는 조항은 "특약사항"이나 맨 뒤 조항에 이어서 넣는다.
  - 양식의 원래 조항 중 정답 데이터에 없는 것은 남겨 둔다. 실제 양식처럼 안내문·빈칸이 섞이게 하려는 것이다. 남긴 문장은 manifest에 "양식 문장(정답 없음)"으로 적는다.
- **`{{...}}` 빈칸은 가짜 값으로 채운다.** 계약서마다 다르게 하고, 모든 값을 manifest에 적는다.
  - 이름: 흔한 성 + 무작위 이름
  - 주소: "서울특별시 ○○구 ○○로 12" 형식
  - 전화: `010-0000-0000`부터 차례로
  - 계좌·주민번호는 넣지 않는다(양식에 칸이 있으면 비워 둔다).
  - **양식에 원래 들어 있던 실제처럼 보이는 이름·주소·연락처도 가짜 값으로 바꾼다.**
- 날짜와 금액은 정답 문장에 있는 값을 그대로 쓴다.

## 4. 저장
- 폴더: `..\datasets\test_hwp_pdfs\`
- 파일명은 영문으로 한다. 지난번 한글 파일명 문제 때문이다. 예: `LAB_toxic_WORK-0001.hwp`, `LAB_toxic_WORK-0001.pdf`
- HWP는 한글의 "PDF로 저장"으로 PDF로 만든다. **텍스트 PDF**여야 한다(스캔 이미지가 아님).
- `manifest.json`에 계약서마다 적는다:
  - doc_id, 종류(toxic/clean), 쓴 양식 파일
  - 조각별 segment_id, label, 넣은 위치(조항 번호 또는 특약)
  - 가짜 값 목록, 남긴 양식 문장 목록
