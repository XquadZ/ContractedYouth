## 1. 이름 가리기 보완 (`rag\pii.py`)
`HWP_TEST_PDFS_FIX.md` B장과 같은 내용이다. 지금 바로 한다.

- **문제:** 실제 양식에서 콜론 없이 나오는 이름이 하나도 안 가려진다. 1차 검사에서 36/36이 미가림이었다.
  - 예: "사업주 최지훈(이하", "임대인 서유진과 임차인 조예준은", "(채권자·갑) 성    명 : 신수아"
- **규칙:**
  - 역할어(사업주·근로자·임대인·임차인·채권자·채무자·보증인·연대보증인·대표자·대리인) **바로 앞에 한글이 붙어 있지 않을 것**
  - 역할어 + 공백 + 2~4글자 한글이고, **바로 뒤가** `(이하`, `과`, `와`, `은`, `는`, `이`, `가`, `/`, `,`, `(`, 공백+`(서명)`, 줄 끝 중 하나일 것
  - 첫 글자가 흔한 성일 것. 성 목록과 제외할 일반 단어 목록은 `HWP_TEST_PDFS_FIX.md` B장을 따른다.
  - "성명 :", "성    명 :", "대 표 자 :"처럼 칸 이름 뒤에 오는 이름도 가린다(사이 공백 수와 상관없이).
  - "갑"과 "을"은 지금처럼 콜론이 있을 때만 가린다.
- **통과 기준 (모두):**
  1. dev 799조각과 test 1,591조각에서 바뀐 조각 **0개**(정답 데이터에는 이름이 없다). 모델은 부르지 않는다. 가리기 함수만 돌린다.
  2. `..\datasets\test_hwp_pdfs_v4_claude\*.pdf` 15장을 서비스와 같은 추출 함수로 뽑았을 때, `manifest_lease.json`·`manifest_lab_loan.json`의 가짜 이름이 가린 뒤 텍스트에 **0번** 나온다.
  3. 기존 테스트 전부 통과
  4. "갑은 을의 신청을 제한하지 않는다", "근로자 대표와 협의한다", "임차인 주거 안정을 고려한다" 등 바뀌면 안 되는 문장 테스트 통과
- 3번 해도 못 넘으면 원래 `pii.py`로 되돌리고 보고한다.

## 2. 점수 공식 수정안 + 기본 모델 EXAONE
- **점수:** "확인 필요가 3개 이상이면 최대 79점" 수정안을 서비스 기본으로 켠다.
  - `rag\score.py`의 `check_cap79` 기본값을 True로 바꾸고, 리포트 생성과 화면 게이지가 **같은 공식**을 쓰게 한다.
  - 단위 테스트에 "위반·위험 0개 + 확인 필요 3개 → 79점, 주의" 케이스를 추가한다.
  - 점수 설명 문구에 한 줄 추가: "확인할 조항이 3개 이상이면 '주의'로 표시해요."
- **모델:** 서비스 기본 `ANALYZE_MODEL=exaone`
  - 카드는 지금 카드(`CARDS_VERSION=tuned`)를 쓴다.
  - 검증 조합은 `out\quant_test\freeze.json`의 **고정 설정**을 쓴다(`axok=False num2way=True ne_risky_only=True num_year_doc=True clean_v2=True R=R0 K=2`). 지금 서비스 설정과 다르면 맞추고, 무엇이 바뀌었는지 적는다.
- **모델 선택 권한:** `/api/settings/model`은 관리자(user1)만 바꿀 수 있게 한다. 일반 사용자가 부르면 403. 일반 사용자 화면에서는 모델 선택 메뉴를 숨긴다.
- **GPT 모드:** OpenAI 크레딧이 소진됐다.
  - 환경변수 `ENABLE_GPT=1`일 때만 GPT 선택지를 보이게 한다(기본은 숨김).
  - GPT 호출이 크레딧·인증 오류로 실패하면 화면에 "외부 AI를 지금 쓸 수 없어요. 로컬 모델로 분석해 주세요."를 띄운다. 서버가 죽거나 빈 결과가 나오면 안 된다.

## 4. 공개 주소 보안
지금 cloudflare 임시 주소로 인터넷에 열려 있다.
- **관리자 비밀번호:**
  - 서버 시작 시 환경변수 `ADMIN_PASSWORD`가 있으면 user1의 비밀번호를 그 값으로 바꾼다(bcrypt).
  - 없으면 16자 무작위 비밀번호를 만들어 `data_local\ADMIN_PASSWORD.txt`(git 제외)에 저장하고 user1에 적용한다. **값은 채팅·로그에 출력하지 않는다.** 사용자에게는 파일 위치만 알려 준다.
  - 8자 예외 주석도 지운다.
- **남용 막기(간단히, 메모리 기반):**
  - 같은 IP에서 가입은 1시간에 5번까지
  - 사용자 1명당 분석은 하루 20번까지. 넘으면 "오늘 분석 횟수를 다 썼어요" 안내
- **터널 안내:** `README.md`에 "공개 주소(cloudflared)는 시연·공유할 때만 켜고 끝나면 끈다"와 켜고 끄는 명령을 적는다. 터널을 자동으로 켜는 코드는 만들지 않는다.
