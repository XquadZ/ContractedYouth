# HWP 시험 계약서 2차 수정 (HWP_TEST_PDFS_FIX2)

`HWP_TEST_PDFS_FIX.md`의 규칙은 그대로 따른다. 사람이 v2 PDF를 직접 열어 보고 찾은 문제만 고친다.
- 결과는 새 폴더 `..\datasets\test_hwp_pdfs_v3\`에 만든다. v1·v2는 지우지 않는다.
- `rag\` 코드는 건드리지 않는다.
- 모델·GPU·판정·평가는 하지 않는다.
- 근로·차용은 아래 작은 것만 고치고, **임대를 주로 고친다.**

## 1. 임대 (5장 모두)
v2(예: `LEASE_toxic_LEASE-0025.pdf`)에서 확인한 문제:
- **양식 조항 문장이 중간에 잘렸다.** 겹치는 부분만 잘라 내서 문장이 깨졌다.
  - 예: 제1조 "다만, 임대인은 물가상승 등을 고려하여 **하고** 임차인은 성실하게 **다**."
  - 예: 제2조 "(임대차기간) **상태로** 2026년 11월 11일까지…"
  - 이 때문에 "한 번만 등장" 검사는 통과했지만, 문서는 망가졌다.
- **정답 조항 전부가 마지막 별지(갱신거절통지서) 뒤에** "특약사항"이라는 제목으로 붙었다. 쪽 번호가 "6 / 5"가 됐다.
- 양식 칸의 날짜(잔금일, 인도일, 작성일 2026년 11월 11일, 통지서의 "2026년 10월 11일 / 조도윤 (서명)")가 정답 조항의 계약기간과 맞지 않는다.

고치는 방법:
1. **양식 조항(제1조~제12조)은 공식 법무부 양식 문구로 되돌린다.**
   - 원본 HWPX 40개를 비교해서, 조마다 가장 많이 나오는 문구를 공식 문구로 쓴다. 다른 파일에만 있는 덧붙은 문장(팀원이 넣은 독소 문장 등)은 공식 문구가 아니다.
   - 문장을 잘라 내지 말고, 조 단위로 통째로 바꾼다.
   - 공식 문구와 정답 조각이 같은 항목을 다루면(예: 제5조 계약의 해제와 "계약의 해제는 관련 법령과…"), **양식 조항 자리를 정답 조각으로 바꾼다.** 같은 주제가 두 번 나오지 않게 한다.
   - 어느 조에 넣었는지는 manifest에 적는다.
2. 자리가 없는 정답 조각은 **본문의 [특약사항] 칸 안**(서명란 앞)에 넣는다.
   - 별지·통지서 뒤에 붙이지 않는다.
   - 양식의 기본 특약 안내 글머리(전입신고·담보권 설정 금지 등 공식 문구)는 남겨도 되고, 정답 조각은 그 아래에 이어서 넣는다.
3. 날짜와 금액은 정답 조각에 맞춘다.
   - 인도일·잔금일은 계약기간 시작일로, 작성일은 시작일보다 앞선 날로 한다.
   - 별지 서식(갱신거절통지서 등)은 빈 서식으로 둔다. 이름·날짜·서명을 채우지 않는다.
4. 정답 조각 밖에 계약별 내용(이름, 금액, 날짜, 특약)이 남아 있으면 안 된다. 다만 위 3번의 양식 칸 값은 예외다.

## 2. 근로 (작은 것)
- 사업장 가짜 값에 업종이 겹쳐 나온다. 예: "카페 카페 봄날 매장"
  - 정답 문장에 "카페 {{사업장_이름}} 매장"처럼 업종이 이미 있으면, 가짜 값에는 업종을 빼고 "봄날"처럼 이름만 넣는다.

## 3. 차용 (작은 것)
- 맨 아래 서명 줄이 "당사자성명서명채권자신수아(서명)채무자윤하은(서명)"처럼 한 줄로 붙어 버렸다.
  - 서명란을 **한글 표**(구분 / 성명 / 서명)로 만든다.
- 제목 "금전차용계약서"는 가운데 정렬하고 굵게, 크게 한다.

## 4. 확인 (`out\test_hwp_pdfs_v3_check.md`)
- FIX의 A-5 검사를 그대로 한다(한 번 / 0번 / 두 번 이상, 금지 문자열, 쪽수, 모든 쪽 PNG는 `out\test_hwp_pdfs_v3_preview\`).
- 추가 검사:
  - **잘린 문장 검사:** 임대 양식 조항(제1조~제12조)의 문구가 공식 문구와 조 단위로 같은지(정답 조각으로 바꾼 조는 빼고). 조마다 "공식 문구 / 정답 조각으로 바꿈 / 다름"을 표로 적는다. "다름"은 0개여야 한다.
  - **쪽 번호:** "n / m"에서 n이 m보다 큰 쪽이 없어야 한다.
  - **정답 조각 위치:** 모든 정답 조각이 서명란보다 앞에 있어야 한다.
- 위반이 있으면 고치고 다시 검사한다. 3번 해도 안 되면 그대로 보고한다.
